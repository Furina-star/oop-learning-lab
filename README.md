# OOP Learning Lab

A Python-based learning repository focused on understanding and applying Object-Oriented Programming through a simplified League of Legends-inspired turn-based combat simulator.

## Objectives

- Strengthen understanding of Encapsulation, Inheritance, Polymorphism, and Abstraction.
- Practice designing classes and assigning responsibilities.
- Explore composition, SOLID principles, and maintainable architecture.
- Develop independent problem-solving and implementation skills.
- Apply automated testing and technical documentation.

## Tech Stack

- Python 3
- pytest
- Git and GitHub

## Project Structure

- `arena/` – Core application logic
- `tests/` – Automated tests
- `docs/` – Learning journal and architectural decisions
- `main.py` – Application entry point 

## Development Approach

The project is developed incrementally through daily learning tasks. Each stage introduces new requirements, implementation challenges, tests, and opportunities for refactoring.

## Learning Journal

The [Learning Journal](docs/learning_journal.md) documents daily learning objectives, implementation examples, challenges, and lessons learned.

- **Day 1: Introduction to Object-Oriented Programming** — Classes and independent objects, instance attributes, initialization with `__init__()` and `self`, instance methods, object state versus return values, and calculating actual health lost when taking damage.
