## Objectives

- Strengthen understanding of Encapsulation, Inheritance, Polymorphism, and Abstraction.
- Practice designing classes and assigning responsibilities.
- Explore composition, SOLID principles, and maintainable architecture.
- Develop independent problem-solving and implementation skills.
- Apply automated testing and technical documentation.

## Project Structure

- `arena/` – Core application logic
- `tests/` – Automated tests
- `docs/` – Learning journal and architectural decisions
- `main.py` – Application entry point 

## Development Approach

The project is developed incrementally through daily learning tasks. Each stage introduces new requirements, implementation challenges, tests, and opportunities for refactoring.
